ExFilTrap is starting…

This desktop app is the monitor for the ExfilTrap detection service. The window opens automatically as soon as the service answers on 127.0.0.1:5050 — this page retries every few seconds.

If you have not started the service yet, run one of:

# root-free demo (recommended first run)
python3 -m exfiltrap.service --demo --fresh-db

# live capture (needs the installed service or sudo)
python3 -m exfiltrap.service --iface YOUR_INTERFACE
