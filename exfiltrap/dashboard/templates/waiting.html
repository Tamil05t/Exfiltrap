Waiting for the ExfilTrap detection service…

This desktop app is the monitor for the ExfilTrap detection service. It switches to the dashboard automatically as soon as the service is running on 127.0.0.1:5050.

Start the detection engine — one click, one root prompt. Network interface to watch:

Headless instead? The engine also runs from a terminal: sudo ./exfiltrap service --iface eth0 (Linux service build) or sudo systemctl start exfiltrap@eth0 (installed service). Windows: install ExFilTrap-Setup.exe — the service auto-starts.
