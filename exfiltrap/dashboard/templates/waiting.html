Waiting for the ExfilTrap detection service…

This desktop app is the monitor for the ExfilTrap detection service. It switches to the dashboard automatically as soon as the service is running on 127.0.0.1:5050.

Start the service (as root):

# Linux — official service build (exfiltrap-linux-service artifact):
sudo ./exfiltrap service --iface YOUR_INTERFACE

# or the installed systemd service:
sudo systemctl start exfiltrap@YOUR_INTERFACE

# Windows: the ExFilTrapSvc service starts automatically at boot;
# manage it with:  exfiltrap.exe winservice start | stop
